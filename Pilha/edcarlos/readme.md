# Solução para o problema do estacionamento envolvendo pilhas

Para compilhar o programa, precisaremos do código da `pilha_estatica.c`. Nesta hierarquia, ele está uma pasta acima. Logo para compilar, use:

```
gcc main.c ../pilha_estatica.c
```

Para rodar:

```
./a.out <input1.txt
```
OBS: Se estiveres no windows, use o `cmd` e, ao compilar, o executável será chamado `a.exe`, assim substitua a chamada por: `a.exe <input1.txt`
