# Exercício sobre o uso das listas duplamente encadeadas

Para compilar: 

```bash
gcc *.c
```

Para Rodar:

```bash
./a.out <input/1.in
```

Se ocultares a parte ```<input/1.in``` o programa ficará aguardando você digitar as duas strings representando os números (sem printar nada);

OBS: No windows, use o git bash para fazer estas operações.
